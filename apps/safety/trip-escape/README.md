## 기본 진행 · v2.3

원본의 한 장면 찾기·스테이지 전환·돌발 퀴즈를 학교의 유형과 장소에 맞게 재구성했습니다. 첫 화면은 정사각형 유형 카드 세 개만 보여주며, 장소 선택은 다음 화면입니다.

- 숙박형: 유형을 누르면 버스 → 휴게소 → 숙소로 바로 시작합니다. 숙소 과제를 마치면 숨겨진 숙소 비상 대피 훈련 → 귀교가 이어집니다.
- 1일형·반일형: 유형 → 별도 장소 선택 → 버스 → 선택 장소의 여러 상황과 필요한 활동 → 귀교입니다. 휴게소·숙소·숙소 비상 미션을 붙이지 않습니다.
- 스테이지 제목, 입장, 칭찬·해설, 클리어, 다음 스테이지는 자동 진행합니다. RPG 대화는 클릭·터치·Enter로 넘긴 뒤 문제를 읽습니다. 학생은 대화와 학습 과제를 조작합니다.
- 영화관의 화재 또는 지진처럼 한 종류를 무작위로 정하며, 전시실의 화재·낙하물, 공원의 물 빠짐·뱀·벌은 해당 장소 안에서 해결합니다. 숙소의 복도 그림을 다른 장소 대피 장면으로 사용하지 않습니다.
- 형아맨은 오른쪽 아래에 작게 표시합니다. 눌러 모은 배지를 확인하고, 배지로 복습한 뒤 진행하던 여행으로 돌아올 수 있습니다.

장소별 자세한 검토표는 [통합 교육활동 설계](docs/통합_교육활동설계.md)에 있습니다. 개별 자료 사용은 선생님 도구 안에 두어 기본 이야기와 섞지 않았습니다.

## 장면 찾기·게임과 학습지원

버스 한 장면에는 안전벨트 없이 일어난 행동과 소화기·비상망치를 함께 배치합니다. 마우스를 가까이 대도 힌트가 나오지 않으며, 정확한 선택 +100점, 빈 곳 선택 −10점, 중복 선택 0점을 적용합니다. 찾으면 형아맨의 ‘잘했어요!’와 해설·짧은 축하 효과가 나타납니다. 점수 때문에 단서나 스테이지를 잃거나 처음부터 다시 하지 않습니다.

스포츠 시설은 준비·차례·점프·휴식, 숙소는 방 점검·정리 전후 비교·야간 도움, 공원은 물가·풀숲·동물과의 거리, 문화유산은 관람 구역·문턱·접근 가능한 경로를 연습합니다. 장소와 관계없는 미니게임은 기본 이야기에서 제외했습니다. 영화관은 출구 확인·불편함 표현·화재·지진 대처에 집중합니다.

큰 영역 대체 버튼·AAC·화면 읽기·동작 줄이기를 제공합니다. 자동 해설은 잠시 표시된 뒤 이어지며, 교사 도구와 자료 팝업을 여는 동안 자동 진행은 멈춥니다. 배지는 스테이지의 해당 장소 과제를 모두 해결했을 때 받습니다. 게임 점수와 배지는 실제 안전 수행의 인증으로 사용하지 않습니다.

## 실행과 수정

빌드나 회원가입이 필요 없는 정적 HTML/JS입니다. 로컬에서는 `index.html`을 열어 볼 수 있고, 전체 주소 동작을 확인할 때는 Node.js에서 다음 명령을 실행합니다.

```text
node tools/preview.mjs
```

미리보기 주소는 `http://127.0.0.1:4173/`입니다.

- `content.js`: 장소별 안전수칙·상황·문제
- `app.js`, `app.css`, `brand.css`: 화면·학습 진행·브랜드
- `activities.js`: 장소별 활동 편성·그림 찾기 좌표·탐험 지도 미션
- `model.js`: 수업 경로·결과·자료 검색
- `mini-games.js`: 미니게임·찾기 점수 상태
- `story.js`: 장소별 이야기·돌발 상황·비상 과제·스테이지 진행
- `resources.js`: 원문 영상·자료 데이터
- `media/illustrations/`: 통일된 캐릭터 그림
- `media/brand/`, `media/ui/`: 전용 글자·형아맨 로고와 UI 그림 32종
- `media/game/`, `media/maps/`: 위험물·비교 그림·탐험 배경
- `media/resources/`: 원본 영상 썸네일

학생 이름과 응답은 서버에 전송하지 않습니다. 이름은 인쇄나 사용자가 선택한 결과 파일에만 포함됩니다. 스테이지 배지는 기본적으로 수업 중 메모리에만 두며 학습지원에서 ‘이 기기에 활동 배지 기억하기’를 켜야 이름 없이 로컬에 보관합니다. 교사 도구에서 지울 수 있습니다.

자세한 출처와 검수 범위는 `docs/`에 기록했습니다.

## v2.3 화면과 그림 수정

- 스테이지 소개는 페이지 전체를 가리는 페이드 화면으로 표시합니다.
- 상황은 RPG 대화창으로 설명하고 클릭·터치·Enter 후 문제를 읽습니다. 대화는 자동으로 닫히지 않습니다.
- 정답에는 제공받은 형아맨·잘했어요 이미지를 전체 화면에 먼저 보여 준 뒤 해설을 보여 줍니다. 음성 사용 시 해설 읽기가 끝난 뒤 이동합니다.
- 이동 돌발 퀴즈는 직전 장면을 멈추고 알림 효과 뒤 팝업으로 나타납니다. 숙소 대피는 별도 스테이지입니다.
- 정사각형 선택지는 모두 같은 배경·테두리이며 손가락 아이콘이 없습니다. O는 파랑, X는 빨강입니다.
- 연결하기는 점을 누른 채 끌어 선을 연결합니다. 두 번 누르기·키보드 선택도 지원하며, 설명 보기는 첫 미완료 짝의 안내선을 잠깐 보여 줍니다.
- 보조 그림 위의 반복 설명은 제거했습니다. 하단은 설명 보기·읽어 주세요·그림으로 말해요입니다.
- 제공받은 로고는 상단에 한 번만 표시합니다. 오른쪽 아래 배지 캐릭터는 투명 배경입니다.
- 상황 그림 42종을 추가했고, 그중 주의·위험 상황 31종은 표정을 다시 교정했습니다. 웃는 초기 시안은 현재 질문에 연결하지 않습니다.

자세한 변경·장소별 활동은 [v2.3 수정 기록](docs/이번수정_v2.3.md), 확인 범위는 [검증 범위](docs/검증_범위.md)를 참조하세요.

## v2.3.1 멈춤 재현·문항 재검토

힌트 소멸 시 재렌더가 칭찬 타이머를 지우는 경우와, 닫은 팝업의 늦은 음성 취소가 다음 이동을 취소하는 경우를 재현해 수정했습니다. 칭찬과 스테이지 타이머를 분리하고 음성 콜백을 현재 재생·팝업에 한정했습니다. 음성 서비스가 시작하지 않거나 실패해도 짧은 읽기 시간 뒤 진행합니다. 정상 음성은 읽기가 끝난 뒤 진행합니다.

기본·보충·장소 돌발·이동 돌발을 포함한 문항 85개와 연결 그림을 [문항별 점검표](docs/문항전수점검_v2.3.1.md)에 정리했습니다. 놀이기구 지진의 낮은 기차 장면, 대피 경로의 연기 조건, 피부 가려움, 벌 발견·공격 구분, 지원 표현, 부정형 OX를 수정했습니다.
