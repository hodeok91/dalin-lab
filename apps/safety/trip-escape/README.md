## 수업 흐름

유형·장소 선택 → 그 장소의 대표 활동 바로 시작 또는 필요한 활동 선택 → 활동 결과와 나의 약속. 영상·그림 찾기·미니게임·퀴즈는 각각 선택할 수 있습니다. 모든 장소에서 같은 단계를 거치지 않습니다.

교사가 여러 장소를 이어 진행할 때만 **선생님 · 목표와 연결 수업**을 사용합니다. 학생에게 버스 동의나 안전 약속 카드 전체 선택을 요구하지 않습니다. 상세 편성·기존 기능 비교는 [통합 교육활동 설계](docs/통합_교육활동설계.md)에 정리했습니다.

유형은 **1일형·숙박형·반일형 현장학습**입니다. 1일형과 반일형에는 휴게소가 포함되지 않습니다. 숙박형에서만 일정에 있을 때 교사가 휴게소를 추가합니다. 버스는 기본으로 넣지 않으며 선생님 수업 도구에서 필요할 때만 추가합니다.

장소는 스포츠 놀이시설, 영화관, 박물관·전시관, 체험관, 놀이공원, 공원·야외, 수목원·식물원, 문화유산·궁궐입니다. 숙박형에는 숙소 생활, 밤 미션, 대피 시뮬레이션을 이어 붙입니다. 숙소만 학습할 수도 있습니다.

## 미니게임과 접근성

- 스포츠: 차례를 기다리고 터치로 점프 5회, 휴식 표현으로 마무리합니다.
- 버스: 그림에서 안전벨트·소화기·비상망치를 직접 찾아 출발 전 점검표를 완성합니다.
- 숙소: 두 장의 정리 전후 그림에서 침대 위 물건·통로의 가방·바닥의 물기 차이를 찾습니다.
- 박물관·영화관·놀이공원·야외·식물원·문화유산: 실제 그림에 맞춘 안전 지점·숨은 관찰 그림을 찾습니다.
- 짝맞추기·같은 그림 찾기·위험 구역 피하기·대피와 신고 순서 카드를 장소에 맞게 편성합니다.
- 영화관·호수공원·스포츠는 형아맨이 움직이는 별도 탐험 지도에서 서로 다른 미션을 선택할 수도 있습니다.
- 숙소 대피: 기존 복도 그림과 손전등으로 소화기·화재경보기·비상구 유도등을 찾는 방식을 유지합니다. 밝게 보기·영역 버튼을 함께 제공합니다.
- 공원·수목원·문화유산: 안전한 지점을 차례대로 선택해 목적지에 도착합니다.
- 체험관: 필요한 안전 행동을 준비 칸에 모읍니다.
- 나머지 장소는 상황 선택·그림 관찰·퀴즈 등 맞는 활동을 사용하며, 불필요한 미니게임을 강제하지 않습니다.

미니게임은 흥미와 연습을 위한 활동이며 결과 점수로 평가하지 않습니다. 교사와 다음 활동으로 이동할 수 있습니다. 배지판은 장소별 연습 참여를 표시합니다. 하트·시간 차감·순위는 없습니다. 배지를 실제 안전 수행 인증으로 사용하지 않습니다.

큰 버튼, 키보드 Tab/Enter/Space 선택, 화면 읽기, AAC 23가지 그림, 글자 크기와 그림 표시 설정, 동작 줄이기를 제공합니다. 시선·손짓·교사의 대리 선택도 수업 응답으로 사용할 수 있습니다.

## 영상·자료

전체 영상의 내용·현재 재생 여부·자막·감각 자극을 전부 검증한 것은 아닙니다. 교사가 수업 전에 확인해야 합니다. 발달단계는 원문의 권장 정보이며 학생의 실제 이해와 의사소통 특성에 맞춰 선택합니다. 문화유산은 전용 영상이 아니라 관람 전 공통 안전 자료를 연결했습니다.

## 실행과 수정

빌드나 회원가입이 필요 없는 정적 HTML/JS입니다. 로컬에서는 `index.html`을 열어 볼 수 있고, 전체 주소 동작을 확인할 때는 Node.js에서 다음 명령을 실행합니다.

```text
node tools/preview.mjs
```

미리보기 주소는 `http://127.0.0.1:4173/`입니다.

- `content.js`: 장소별 안전수칙·상황·문제
- `app.js`, `app.css`, `brand.css`: 화면·학습 진행·브랜드
- `activities.js`: 장소별 활동 편성·그림 찾기 좌표·탐험 지도 미션
- `model.js`: 수업 경로·결과·자료 검색
- `mini-games.js`: 미니게임 상태
- `resources.js`: 원문 영상·자료 데이터
- `media/illustrations/`: 통일된 캐릭터 그림
- `media/brand/`, `media/ui/`: 전용 글자·형아맨 로고와 UI 그림 32종
- `media/game/`, `media/maps/`: 위험물·비교 그림·탐험 배경
- `media/resources/`: 원본 영상 썸네일

학생 이름과 응답은 서버에 전송하지 않습니다. 이름은 인쇄나 사용자가 선택한 결과 파일에만 포함됩니다. 활동 배지는 기본적으로 수업 중 메모리에만 두며 학습지원에서 ‘이 기기에 활동 배지 기억하기’를 켜야 이름 없이 로컬에 보관합니다. 교사 도구에서 지울 수 있습니다.

자세한 출처와 검수 범위는 `docs/`에 기록했습니다.
