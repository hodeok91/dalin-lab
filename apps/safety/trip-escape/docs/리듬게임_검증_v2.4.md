# v2.4 리듬 게임 검증

2026-11-14

- 전체 자동 테스트 79개 통과, 실패 0개. 기존 이야기 자동 진행·음성 실패·힌트 경합·문항 그림 경로 검사를 포함한다.
- 새 리듬 논리 테스트 8개: 연타 중복, 이른/늦은 입력, 기다림/멈춤, 따라하기, 일시정지 시간 보존, 속도, 휴식 표현, 카운트다운 입력.
- 위젯 테스트 3개: 팝업 중 시계 정지, 게임 이탈 시 프레임 종료, 소리 미지원 시 시각 신호 진행.
- 실제 Edge에서 12박자를 진행하고 8회 점프 후 휴식 표현 화면까지 도달했다. Space 입력 후 박자 성공 상태도 확인했다.
- 실제 실행 캡처 32장에 기록된 페이지 오류는 0개. 캡처 파일 SHA-256과 28개 배치의 캡처 존재 여부를 배치표 생성기가 검사한다.
- 1440×1080 및 1024×768 화면을 확인했다. 전자칠판·태블릿 실기기 터치 감도와 오디오 출력, 학생 대상 사용성은 별도 확인이 필요하다.

## 동작

50 BPM(느린), 75 BPM(보통). 점프 8박자·기다림 2박자·멈춤 2박자로 구성된다. 시각 신호와 짧은 박자음을 제공하며 소리를 끌 수 있다. 따라하기에서는 점프 신호가 입력을 기다린다. 놓치거나 잘못 누르면 해당 박자를 다시 보여주고 실패·감점·처음부터 재시작을 강요하지 않는다. 팝업과 숨겨진 탭에서는 박자가 멈춘다. 마지막에는 쉬고 싶다고 표현해야 완료한다.

캐릭터는 원래 HA 복장 형아맨 이미지이며 반려된 초록 옷 시안은 앱에서 참조하지 않는다.
