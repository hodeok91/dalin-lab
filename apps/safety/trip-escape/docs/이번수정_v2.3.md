# 이번 수정 · 안전의 달인 v2.3

2026-11-14. 기존 이야기 흐름을 유지하면서 사용자 화면 피드백을 반영했다.

## 화면과 조작

- 유형 선택 → 필요한 경우 별도 장소 선택 → 해당 이야기의 스테이지를 진행한다.
- 스테이지 소개는 페이지 전체 배경을 어둡게 가리는 페이드 장면이다. 소개·클리어·이동은 자동이다.
- 상황은 RPG 대화창에서 설명한다. 클릭·터치·Enter로 넘길 때까지 기다리며, 넘긴 뒤 문제를 읽는다.
- 정답 직후 전체 화면에 제공받은 형아맨과 ‘잘했어요!’를 먼저 표시하고 해설을 따로 보여 준다. 음성을 켠 경우 읽기 종료 후 자동 이동한다.
- 돌발 퀴즈는 직전 장면을 멈추는 효과 뒤 팝업으로 나타난다. 숙소 대피는 팝업이 아닌 별도 스테이지를 유지한다.
- 화재·지진 등 한 장소에서 일어나는 돌발 사건은 실행마다 한 종류만 선택한다. 같은 사건 안의 보호·이동 등 관련 행동은 연결한다.
- 선택지는 정사각형이며 모두 같은 배경·테두리다. O는 파랑, X는 빨강이다. 선택 전 정답 강조와 손가락 아이콘이 없다.
- 하단은 설명 보기·읽어 주세요·그림으로 말해요다. 문제 옆 중복 도구와 불필요한 그림 위 설명은 제거했다.
- 찾기에서는 마우스를 가까이 대도 정답 영역을 드러내지 않는다. 명시적으로 설명 보기를 눌렀을 때만 잠깐 힌트를 보여 준다. 버스는 ‘위험한 행동 1곳’ 빨강, ‘안전장치 2곳’ 초록이다.
- 연결하기는 왼쪽 점을 누른 채 오른쪽 점까지 끌어 놓으면 선이 이어진다. 잘못 연결하면 선을 남기지 않는다. 두 번 누르기·키보드 조작도 가능하다. 설명 보기는 첫 미완료 항목의 안내선을 잠깐 보여 준 뒤 지운다.
- 로고는 상단에 한 번 표시하며 오른쪽 아래 배지 캐릭터는 실제 알파 투명 이미지다.

## 장소별 활동 위치

| 장소 | 기본 이야기 안의 활동 | 상황 선택·확인 내용 |
|---|---|---|
| 버스 | 한 장면 위험 행동·소화기·비상망치 찾기 | 이동 중 착석, 하차 후 횡단, 확인 퀴즈 |
| 스포츠 놀이시설 | 준비 카드, 차례를 지키는 터치 점프·휴식 | 친구 다침, 어지러움, 무작위 화재 또는 지진 |
| 영화관 | 출구·통로·선생님 찾기 | 소리 불편 알림, 무작위 화재 또는 지진 |
| 박물관·전시관 | 관람선·출구·선생님 찾기, 점과 선 연결 | 전시물 이용 확인, 일행 찾기, 의사소통, 확인 퀴즈, 무작위 비상 상황 |
| 체험관 | 안전 준비 카드 | 뜨거운 도구, 시범 다시 요청, 무작위 비상 상황 |
| 놀이공원 | 한 장면에서 위험 행동 네 곳 찾기 | 울타리 안 물건, 안전장치·하차, 일행 찾기, 기구에서 지진 안내 |
| 공원·호수공원·생태공원 | 안전 지점 찾기, 물가·풀숲·위험 구역 피하기 | 물가 물건, 피부 불편, 폭염 휴식, 뱀·벌 또는 익수 목격 |
| 수목원·식물원 | 열매·젖은 바닥·관찰로 찾기, 관찰로 길 찾기 | 모르는 열매, 벌과 거리 두기 |
| 문화유산·궁궐 | 출입 제한 줄·돌계단·길 찾기, 관람길 미션 | 문턱·접근 가능한 경로, 촬영 구역, 지진 보호와 집결 |
| 숙소 | 방 안전 찾기, 정리 전후 다른 그림 찾기, 도움 표현 선 연결 | 출입 확인, 건강·야간 이동·약 확인 |
| 숙소 대피 | 손전등 안전장치 찾기, 대피·신고 순서 놓기 | 알림, 확인된 경로, 이동 지원, 대피가 어려운 경우 구조 요청, 집결 |
| 휴게소 | 위험 행동 찾기 | 화장실 동행·일행과 떨어진 경우, 이동 중 돌발 퀴즈 |
| 귀교 | 상황 선택 | 정차 전 착석, 하차 후 인원 확인 |

같은 그림 찾기는 선생님 → 개별 활동 자료에서 스포츠·영화관 등의 보충 활동으로 선택할 수 있다. 모든 장소에 같은 미니게임을 강제하지 않는다. 1일형·반일형에는 휴게소와 숙소 대피를 붙이지 않는다.
