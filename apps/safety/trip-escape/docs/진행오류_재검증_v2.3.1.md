## 재현한 결함과 수정

| 재현 조건 | 이전 결과 | 수정 |
|---|---|---|
| 마지막 요소 직전에 설명/힌트를 사용 | 힌트 소멸의 화면 갱신이 칭찬·해설 타이머까지 지워 멈춤 | 칭찬 전용 타이머를 스테이지 전환 타이머와 분리 |

| 음성 API는 있으나 서비스가 시작하지 않음 | 긴 음성 대기 시간 동안 멈춘 것처럼 보임 | 음성 시작 전에는 3.5~8초의 텍스트 읽기 시간 뒤 진행 |
| 음성 오류·동기 예외·종료 이벤트 누락 | 환경에 따라 진행 보장 약함 | 오류 처리·음성 재생 상태 확인·별도 대기 종료 경로 |
| 실제처럼 뒤늦게 팝업 close 이벤트 도착 | 기존 검사에서는 이벤트를 생략 | 비동기 close를 발생시키는 검사로 변경 |

두 최초 재현 검사는 수정 전 실패하고 수정 후 통과했다. 이미 찾은 요소·점수·스테이지 기록을 초기화하지 않는다. 진행 도중의 대화창은 사용자 요청대로 클릭·터치·Enter를 기다린다.
