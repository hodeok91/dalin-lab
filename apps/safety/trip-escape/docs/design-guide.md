# 캐릭터와 화면 디자인 기준

앱 이름: 안전의 달인. 기준일: 2026-11-13.

사용자 제공 남녀 선생님·형아맨의 캐릭터 시트를 기준으로 한다. 형아맨의 얼굴·갈색 머리·흰 슈트·HA 표시·파란 장갑과 부츠를 유지한다. 교사는 얼굴·머리·안경·비율을 유지하고, 장소에 맞는 편한 옷과 낮은 운동화를 입힌다.

## 그림

짙고 정돈된 선, 넓고 명료한 색면, 두세 단계 셀채색을 사용한다. 배경에도 같은 표현을 적용한다. 사진 같은 재질·광택 바닥 반사·3D 렌더링·렌즈 흐림을 섞지 않는다. 안전을 판단하는 핵심 물체·표식·행동은 바꾸지 않는다.

장소 장면은 `media/illustrations/{장소}.webp`, AAC는 `aac-{의미}.webp`를 사용한다. 옛 캐릭터 그림은 학습 화면에서 참조하지 않는다. 외부 영상 썸네일은 원본 출처 자료이므로 캐릭터 그림으로 다시 그리지 않고 출처를 표시한다.

## 화면

캐릭터를 작은 장식으로 넣은 대시보드가 아니라, 그림을 중심으로 학생이 한 행동씩 고르는 교재 화면으로 만든다. 크림색 종이, 진한 잉크선, 형아맨 복장의 파랑, 따뜻한 살구·연두 색면을 사용한다. 과한 광택·배경 그라데이션·유리 효과·네온은 사용하지 않는다.

홈에는 유형·장소 선택과 캐릭터 화풍의 안전 탐험판을 둔다. 배지는 연습 참여를 격려하며 실제 안전 수행 인증이나 순위로 사용하지 않는다. 장소에서는 해당 활동을 바로 시작하고, 영상·퀴즈·게임은 필요에 맞게 골라 쓴다. 모든 장소에 똑같은 단계를 강제하지 않는다.

정답·오답·완료는 색에만 의존하지 않고 문장과 기호로 표시한다. 필요한 설명을 숨기기 위해 정답 버튼을 키보드에서 제외하지 않는다. 갑작스러운 경고음이나 화면 흔들림을 사용하지 않는다.

## 제작 도구와 기록

이미지 생성·수정은 built-in image_gen 도구를 사용했다. 참고 시트 원본은 `E:/안전교육/캐릭터원본/`에 별도 보관하며 공개 배포 파일에는 포함하지 않는다. 개별 프롬프트·시각 검수 기록은 `aac-style.md`, `scene-style.md`, `teacher-outfits.md`를 따른다.
