## 스포츠 리듬 게임

친구 차례 → 준비 3박자 → 점프 8회와 기다림·멈춤을 포함한 12박자 → 쉬고 싶다고 표현하기 순서다. 기준선에 맞춰 눌러야 점프하며, 노랑·빨강 박자에 계속 누르면 해당 박자를 다시 연습한다. 놓친 박자는 초기화·감점 없이 반복한다. 느린/보통 박자, 누를 때까지 기다리는 따라하기, 박자음 끄기, 잠깐 쉬고 이어하기를 제공한다. 원래 HA 복장의 형아맨을 사용하며, 반려된 초록 옷 시안은 앱이나 배포본에서 참조하지 않는다.

## 공원 생존 피하기

공원 기본 이야기의 피하기 과제와 선생님 메뉴에서 실행한다. 위에서 위험 그림이 내려오며 화면의 왼쪽·오른쪽 키 또는 PC 방향키로 움직인다. 남은 기회 3번, 시간 1초당 10점과 피한 그림당 50점으로 생존 기록을 겨룬다. 진행할수록 속도가 올라가며 천천히/보통 모드의 기록은 나눠 비교한다. 팝업·탭 숨김·잠깐 쉬기에서는 게임과 점수가 멈춘다. 도전 종료 후 이번 점수·최고 점수·상위 5개 기록을 보고 다시 도전하거나 다음 과제로 간다. 이름 없이 같은 기기의 기록만 보관한다.

## 위험·안전 행동 찾기

9곳의 32개 대상을 위험한 행동·장소, 안전한 행동, 안전장치·표지로 구분했다. 공원은 난간이 아니라 난간에 발을 올린 친구를 찾는다. 수정한 상황 그림 6장과 기존 그림 3장을 사용하며 모든 찾기 문장이 실제 동작·색·위치를 가리킨다.

## 실제 화면 확인 범위

REA가 별도의 로컬 Edge 프로필에서 학생/선생님 화면을 클릭해 PNG를 캡처했다. 합성 시안이나 이미지 생성 결과를 게임 화면으로 표시하지 않았다. 대부분은 검토 시간을 줄이기 위해 선생님 → 개별 활동 자료로 실행했고, 기본 이야기 스포츠 과제도 별도로 캡처했다. 모든 최종 캡처 시나리오는 완료 상태이며 페이지 오류가 없다. 리듬 12박자 진행과 키보드 Space 점프도 실제 브라우저에서 확인했다. 실제 전자칠판·태블릿 하드웨어의 손가락 감도, 소리 출력, 학생별 사용성까지 확인한 것은 아니다.
