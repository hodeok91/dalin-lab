# 피버·콤보와 실제 게임 검증 · v2.8

2026-11-15, Node 자동 검사 153개 통과·실패 0개. 실제 Edge의 1440×1080 / 1024×768 / 390×844 화면에서 그림·넘침·입력·진행을 확인했습니다. 전자칠판 실물은 연결하지 않았으며 터치는 브라우저의 네이티브 터치 입력으로 확인했습니다. 실제 브라우저 수치는 실제브라우저_검증_v2.8.json에 있습니다.

## 산책길

- 쉬움·보통·어려움·매우 어려움, 기본 보통. 시작 파형 시간은 각각 5200·2400·1800·1400ms입니다. 노말·도전 모두 피버를 사용합니다.
- 안전하게 넘긴 파형만 콤보가 올라갑니다. 피버 XP는 15+min(콤보,5)×3이며, 첫 5연속 회피의 18+21+24+27+30으로 100에 도달합니다.
- 피버는 5파형, 장애물 이동 속도 1.3배·좌우 이동 1.45배·획득 점수 2배입니다. 점수에는 생존 시간·실제 회피·실제 별 획득만 반영합니다.
- 피버 중 충돌은 하트를 깎지 않고 방어 링을 보여 줍니다. 충돌을 회피·별·콤보로 세지 않습니다. 피버가 끝난 다음 충돌은 하트를 깎고 콤보·XP를 초기화합니다. 실제 충돌 검사에서 3/3 하트를 유지하고 방어 1회를 기록했습니다.
- 도전의 망토는 실제로 착용한 형아맨 2프레임 달리기와 점프 그림입니다. 망토를 먹었을 때 낮은 가지를 넘고, 벌·뱀·물에는 우회로를 남깁니다.
- 키보드·마우스 버튼·터치 유지 이동, 놓으면 정지, 일시정지·탭 숨김·재시작을 확인했습니다. 기록 규칙 버전 4로 이전 점수와 구분합니다.

## 리듬

- 노래·노트 속도는 그대로이며 실제 WAV 재생 위치를 시계로 씁니다. 정상 노트 173개(점프 151·멈춤 22), 네 난이도와 노래 전체 149.84초를 유지합니다.
- 올바른 점프·멈춤에 콤보와 XP 8+min(콤보,10)을 더합니다. 첫 8연속 성공으로 피버가 시작되고 노래 시간 8초 동안 점수 2배입니다. 시작시킨 노트는 기본 점수를 받습니다.
- 정확 100→200, 좋아요 80→160, 성공 50→100, 멈춤 50→100. 실제 키 입력에서 정확 판정 +200점을 확인했습니다. 놓침·잘못 누름은 콤보·XP를 끊습니다. 진행 중인 피버는 원래 종료 시각까지 유지합니다.
- 일시정지 시 노래와 피버 시간이 함께 멈춥니다. 게임 중 다른 효과음·배경음·TTS 없이 제공된 WAV만 재생합니다. 재시작에서 점수·콤보·피버를 초기화합니다.

## 퀴즈

- 문항 하나를 완전히 맞추면 콤보 1, 기본 +100점. 매 3연속마다 추가 +50점입니다. 실제 3문항 결과는 100+100+150=350점입니다.
- 그림 찾기는 대상마다 이미 +100점이므로 문항 완료 시 기본점을 중복 지급하지 않습니다. 신고처럼 대상이 여럿이어도 문항 콤보는 완료 때 한 번만 셉니다.
- 오답·잘못된 곳 클릭은 콤보를 초기화합니다. 같은 문항을 반복해 콤보·점수를 얻지 못하게 문항별 지급을 기록합니다. 도움 표현처럼 두 응답이 모두 유효한 문항에는 채점을 적용하지 않습니다.
