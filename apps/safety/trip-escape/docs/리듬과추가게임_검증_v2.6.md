# 노래·새 장소·미니게임 검증 · v2.6

2026-11-15. 이 문서는 로컬 구현과 확인 범위를 기록한다. GitHub push나 홈페이지 배포 완료 기록은 아니다.

## 제공한 노래로 끝까지 하는 리듬 점프

- `audio/safety-jump.wav`는 제공된 원본과 SHA-256이 같다. 48kHz 16비트 스테레오, 149.84초다.
- 박자 신호를 분석해 약 140 BPM의 두 박자 간격을 기본으로 노트를 편성했다. 점프 151개와 멈춤 22개, 총 173개다. 노트 목록·추정 방법·멈춤 구간은 `노래_박자와노트_v2.6.json`에 있다. 음성 인식 결과를 정확한 가사 전사로 표시하지 않는다.
- 기다려요 이미지는 시작 전·잠깐 쉬기 안내다. 플레이 노트는 점프와 멈춰요 두 종류만 사용한다. 점프는 타이밍에 누르고 멈춤은 누르지 않는다.
- 정확해요·최고예요·좋아요는 실제 노트 시각과 입력 오차로 판정한다. 멈춤에서 누르면 아차, 놓친 점프는 다시 이미지를 표시한다. 같은 노트 연타는 점프·점수를 중복 지급하지 않는다.
- 노트 시계는 RAF 경과 시간이 아니라 실제 `Audio.currentTime`이다. 느리게·잠깐 쉬기·재개·팝업·탭 숨김에서 곡과 노트가 함께 움직인다. 마지막 노트 통과만으로 끝내지 않고 실제 `ended` 이벤트 뒤 휴식 표현으로 마무리한다.
- 이 미니게임에서는 제공된 WAV만 재생한다. 공통 효과음·배경음·TTS를 억제하며, 억제 전에 예약된 효과음도 중단한다.
- 실제 Edge에서 곡 전체를 재생하고 중간 점프·일시정지·재개를 조작한 뒤 종료 화면까지 관찰했다. 약 155.8초 시나리오가 완료됐고 페이지 오류는 없었다. 전체 노트에서 손으로 정답을 모두 누른 것이 아니라 실제 오디오 종료·노트 진행·재개를 확인한 것이다. 모든 노트의 정답·오답·중복 입력은 상태 검사로 별도 확인했다.

## 장소별 구현

| 장소 | 추가·개선한 활동 | 유지한 조건 |
|---|---|---|
| 영화관 | 격자 통로 미로가 본편에도 등장 | 상영 종료 뒤 평상시 출구 이동. 실제 재난 경로를 외우게 하지 않음 |
| 일반 공원·놀이터 | 튀어나오는 젖은 바닥·풀숲·벌 발견 알리기 | 직접 치우기·때리기 아님. 놓친 그림은 다시 등장. 그림 기다리기 모드 제공 |
| 호수공원 | 기존 생존 피하기 유지 | 좌우 키·화면 버튼, 시간과 실제 회피 점수, 속도별 기록 |
| 생태공원 | 안내자의 걷기·멈춤 신호 | 3구간, 누르고 있기와 한 번씩 켜고 끄기 대안 |
| 박물관·전시관 | 관람 행동 비교 찾기 | 관람 줄을 넘는 다리·유리장에 뻗은 손·바닥 음료, 세 대상만 완료에 반영 |
| 체험관 | 움직이는 컨베이어의 도구 분류 | 오늘 안내받은 도구와 어른 담당 도구를 구분. 드래그·두 번 누르기 지원 |
| 문화유산 | 표지와 행동의 선 연결 | 출입 제한·계단 주의·비상구의 뜻을 구체적 행동에 연결 |
| 놀이공원 | 탑승 순서 6단계 | 3단계에서 끝나는 기존 고정값 제거. 오답은 다시 선택 |
| 농촌·동물체험장 | 손 씻기 순서와 6부위 연습 | 버튼 연타로 30초를 채울 수 없음. 물·비누·각 부위·헹굼·말리기 구분 |
| 물놀이시설 | 오늘 장비 준비 | 수영모·수영복·구명조끼와 부적합한 목도리, 준비 칸 위치 확인 |
| 도서관·공연장 | 목소리 크기 연습 | 마이크 또는 그림 버튼. 도움 요청을 참게 하지 않음 |
| 숙소·대피 | 기존 방 정리·손전등·대피 분기 유지 | 다른 장소에 숙소 비상 장면을 붙이지 않음 |

목소리 연습은 영화관·박물관·체험관·문화유산의 선생님 개별 활동에도 제공한다. 해당 장소 그림과 관람·설명 시간 문구를 사용한다.

## 마이크와 입력

사용자가 마이크 시작을 눌렀을 때만 권한을 요청한다. `getUserMedia`의 입력을 `AnalyserNode`에서 RMS로 계산한다. 녹음·서버 전송·스피커 출력 연결이 없고, 주변 소리를 2초 동안 보정한 상대 크기만 사용한다. 데시벨 계측값이나 학생 발성 능력 평가로 표시하지 않는다.

권한 거절·미지원에는 그림 대안이 있다. 허용 대기 중 그림으로 전환하거나 화면에서 나가면 나중에 도착한 스트림도 닫는다. 팝업·탭 숨김·완료·페이지 이탈에서 트랙과 오디오 컨텍스트를 정리한다. 재연결은 사용자가 선택한다.

도구·물놀이 카드는 포인터 이동 후 실제 도착한 준비 칸을 확인한다. 맞지 않는 곳이나 바깥에 놓으면 완료 수가 오르지 않는다. 카드→칸을 차례로 누르는 방식도 같은 상태 검사를 사용한다. 선 연결은 기존 SVG 드래그·터치와 두 번 누르기를 유지한다.

## 확인 결과와 한계

- 19개 스테이지, 여행 세 유형, 장소별 사건 분기, 정상·무음·오류 음성 및 비동기 팝업 닫기에서 완료까지 진행했다.
- 선택·지원·OX·장소 사건 104문항과 별도 버스 이동 돌발 1문항을 검토했다. 모든 주요 선택 장면에 파일을 연결하고 파일 존재를 검사했다.
- 실제 Edge 캡처에서 미로·비교 찾기의 격자 클래스가 외부 컨테이너에도 걸리던 배치를 발견해 분리했다. 미로 조작 키는 지도 옆에, 6단계 탑승 순서는 작은 진행칸과 카드 그리드로 정리했다.
- 수영장 그림의 평상복·운동화·장화를 수영복·수영모·맨발로 수정했다. 준비 학생도 수영복으로 맞췄다. 생태공원의 벌 그림은 야외로 구분했다.
- 자동 검사와 실제 브라우저 실행은 프로그램·화면 검증이다. 전자칠판·태블릿의 실제 터치 감도, 현장 마이크·스피커 출력, 학생별 사용성이나 실제 안전 수행을 인증하지 않는다.

실제 화면·해시·증거 ID와 현재 배치 위치는 `미니게임_배치표_v2.6.md` 및 별도 캡처 갤러리를 참조한다.

최종 자동 검사는 127개가 모두 통과했다. 앱의 20개 진입 화면과 배포 파일 1,035개의 로컬 SHA-256·HTTP 응답 SHA-256을 확인했으며 누락은 0개였다. 갤러리는 현재 배치 41곳(본편 32·보충 9)과 실제 화면 48장을 담는다. 변경하지 않은 v2.5 활동 화면은 이전 버전을 표시했다.
