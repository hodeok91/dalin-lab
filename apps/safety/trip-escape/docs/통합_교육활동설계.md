# 안전의 달인 — 통합 교육활동 설계

기준일 2026-11-14. 사용자 요구, 복구한 기존 게임, 첨부한 GPT 기획·프로토타입을 비교해 구현한 내용이다. 첨부 기획의 기술·플랫폼 제안은 참고 자료이며 별도 배포 지시로 취급하지 않았다.

## 장소에 맞는 활동을 고르는 자료

학생이 장소를 열면 그곳의 대표 활동을 바로 시작한다. 사전 동의·버스 확인·목표 문제·O/X를 모든 장소의 입장 조건으로 요구하지 않는다. 퀴즈, 영상, 그림 탐색, 미니게임은 각각 필요한 때 선택한다. 교사의 연결 수업만 여러 장소와 문항을 순서대로 진행한다.

| 장소 | 대표 활동 | 필요한 추가 활동 |
|---|---|---|
| 버스 | 실제 그림에서 안전벨트·소화기·비상망치 찾기와 점검표 | 승하차 상황, 버스 약속 퀴즈, 영상 |
| 스포츠 놀이시설 | 차례 기다리기 → 터치 점프 5회 → 휴식 표현 | 준비 카드, 다침·어지러움 도움 요청, 같은 그림 찾기 |
| 영화관 | 비상구·통로·선생님 찾기 | 어두운 통로의 안전한 길, 감각 불편 표현, 같은 그림 찾기 |
| 박물관·전시관 | 전시 그림에서 관람선·출구·선생님 찾기, 숨은 투구 | 상황과 행동 짝맞추기, 관람 예절 퀴즈·상황 |
| 체험관 | 안내·도구·재료를 확인하는 준비 카드 | 도움 표현 짝맞추기, 뜨거운 도구·모르는 방법 상황 |
| 놀이공원 | 줄·탑승·울타리·이동 상황의 그림 찾기 | 떨어진 물건·탑승 상황 짝맞추기, 일행 이탈 도움 요청 |
| 공원·야외 | 물가·풀숲·벌·뱀·젖은 바닥을 피해 걷기 | 호수공원 그림 찾기, 안전한 길, 익수 목격·피부 불편·야생동물 상황 |
| 수목원·식물원 | 열매·젖은 바닥·관찰로 그림 찾기 | 관찰로 이동, 모르는 열매·벌 상황 |
| 문화유산·궁궐 | 문턱·계단·관람 구역을 확인하는 길 찾기 | 줄·돌계단 찾기, 숨은 지붕 장식, 접근 가능한 경로 요청 |
| 숙소 | 방의 침대·창문·콘센트·가방 찾기 | 정리 전후 다른 그림 찾기 3곳, 밤의 도움 짝맞추기, 출입 확인 |
| 밤 미션 | 통로·연락·화장실 이동 준비 카드 | 건강·화장실·도움 요청 상황 |
| 대피 | 기존 복도의 손전등 안전장치 3곳 찾기 | 대피 행동 순서, 119 구조 요청 순서, 대피 가능·불가능·이동 지원 상황 |
| 휴게소 | 뜨거운 음식·일행·젖은 바닥 그림 탐색 | 이동·매점·주차장 상황. 숙박형 일정에 실제 있을 때만 추가 |

비교 그림은 동일한 숙소 원화를 편집해 가방·침대 위 물건·물기 세 곳만 바뀌게 제작했다. 무작위 차이 찾기가 아니라 통로 정리와 미끄러짐 예방을 설명한다. 쏟아진 물은 혼자 치우라고 평가하지 않고 교사에게 알리도록 안내한다.

## GPT 시안과의 결합

탐험 화면·형아맨 이동·장소 미션·배지판을 채택했다. 영화관·스포츠·호수공원에는 별도의 일러스트 맵이 있고, 각 지점에서 서로 다른 장소 활동을 연다. 화살표 이동과 미션 바로 선택을 함께 제공하며 정밀 조작·반응 속도를 입장 조건으로 사용하지 않는다. 장소마다 무조건 같은 세 단계나 같은 퀴즈를 반복하지 않는다.

임시 캐릭터와 이모지 아이콘은 캐릭터 시트 기반 그림으로 교체했다. 형아맨 원형과 HA 복장은 유지하고 교사는 편한 옷과 운동화를 착용한다. 전용 글자 로고·캐릭터 로고·UI 32개·AAC 23개·장소 그림·지도·위험물까지 연결한다. 외부 교육 영상 썸네일은 원본 출처 이미지로 유지한다.

첨부안의 EXE/APK·단일 스위치 자동 스캔·교사용 콘텐츠 제작기·로그인별 기록 서버는 이번 정적 웹 구현에 포함하지 않았다. 구현한 기능과 향후 아이디어를 혼동하지 않는다.

## 이동 자료와 기록

버스는 기본 일정에 넣지 않는다. 교사가 도구에서 켠 경우에만 연결 수업에 추가한다. 숙박형만 휴게소 선택을 제공한다. 장소별 직접 주소와 영상 목록의 조건 공유는 유지한다.

활동 완료·도움 여부는 수업 중 메모리에 둔다. 학습지원의 ‘이 기기에 활동 배지 기억하기’를 켰을 때만 이름 없이 장소·활동 ID·완료 시각·도움 여부를 브라우저에 보관한다. 공용 기기에서 끄거나 교사 도구에서 지울 수 있다. 이름은 인쇄·수동 결과 파일에만 사용한다. 서버로 전송하지 않는다.

교사는 실제 시설의 동선·비상구·난간·이용 기준과 학생별 이동·건강·감각·의사소통 지원을 현장에서 확인한다. 게임의 완료·배지만으로 실제 안전 행동을 판단하지 않는다.
