기준일 2026-11-14. 기본은 원본처럼 한 장면의 과제 해결 → 해설 → 다음 스테이지다. 기능이 작동하는지와 안전교육 내용이 충분한지는 별도로 검토한다.

## 유형별 경로

숙박형은 선택 즉시 버스·휴게소·숙소로 시작한다. 숙소 안의 여러 상황을 해결한 뒤에만 숙소 비상 대피 훈련이 나타나며, 안전한 집결과 귀교로 마무리한다. 1일형·반일형은 유형과 장소를 서로 다른 화면에서 선택한 뒤 버스·선택 장소·귀교로 이어진다. 두 유형에는 휴게소·숙소·숙소 대피를 끼워 넣지 않는다.

장소별 공유 주소는 그 장소의 이야기만 연다. 공유된 영화관·공원 자료에 숙소 대피를 자동으로 붙이지 않는다.

## 그림과 설명

버스 장면 찾기는 잘못된 행동과 안전장치가 함께 있는 별도 그림을 제작했다. 달리는 버스 안에서 자리를 지키는 그림과 하차 후 길을 건너는 야외 그림도 각각 연결했다. 주요 상황 선택 문항은 전용 상황 그림을 연결했다. OX 복습의 보조 그림에는 불필요한 상단 설명을 붙이지 않는다. 화재·지진·익수·불편함 등의 표정은 침착함·걱정·집중에 맞춰 교정했다. 숙소 복도 그림은 숙소 대피에만 사용한다.

## 원본과 자동 전환

원본 https://kimju1416.github.io/trip-escape/ 의 공개 HTML을 읽어 비교했다. 원본은 숙소 위험 찾기를 마친 뒤 ‘잠들기’에서 한밤 대피 스테이지로 넘어간다. 이번 사용자 지시에 따라 스테이지 제목·칭찬·해설·클리어·숨은 비상 미션은 추가 시작·다음 버튼 없이 자동 전환한다. RPG 상황 대화는 클릭·터치·Enter로 넘기며, 그다음 문제를 읽는다. 학생은 대화와 장면 찾기·답 고르기·필요한 게임을 조작한다. 교사 팝업·자료실에서는 자동 진행을 멈추고 돌아오면 이어 간다.

정확한 찾기 +100·빈 곳 −10·중복 0점이다. 점수와 관계없이 이미 모은 단서·진행을 잃지 않는다. 잘못된 답은 같은 상황을 다시 고르며, 올바른 답에는 형아맨의 ‘잘했어요!’와 이유를 보여준다. 장소 비상 과제까지 마쳐야 스테이지 배지를 준다. 배지 복습은 진행하던 여행을 따로 보존한다.
