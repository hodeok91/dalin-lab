# 검증 범위와 결과 · 스토리형 v2.3

2026-11-14. 자동 검사 41개 통과. 실제 출력은 검증결과.txt에 보존했다.

## 진행과 조작

- 1일형·반일형은 별도 장소 선택 후 버스로, 숙박형은 바로 버스로 시작한다. 1일형·반일형에 휴게소·숙소·숙소 대피를 넣지 않는다.
- 14개 장소 이야기와 세 유형의 전체 경로, 배지 복습 후 복귀를 가상 시계와 실제 DOM 이벤트로 검사했다.
- 스테이지 소개는 전체 화면이다. 대화는 60초를 기다려도 자동으로 닫히지 않고 클릭·Enter 후 문제 읽기를 호출한다. 소개·칭찬·해설·클리어·이동은 자동이다.
- O 파랑·X 빨강, 선택 전 카드의 동일 배경·테두리, 손가락 아이콘과 반복 보조 문구 제거를 검사했다.
- 찾기는 근접 강조가 없으며 정확한 선택 +100·빈 곳 −10·중복 0점이다. 점수 때문에 진행을 잃지 않는다.
- 드래그·터치 포인터 이동으로 선이 생기고 올바른 짝만 연결한다. 힌트 안내선은 잠시 후 사라지고 이미 연결한 선은 유지한다.
- 이동 돌발은 프리징 뒤 팝업으로 열리고 숙소 대피는 별도 스테이지다. 화재·지진은 한 종류를 무작위 선택하며 지진 경로도 완주했다.
- 점프·차례·휴식, 손전등, 다른 그림, 짝맞추기, 같은 그림, 길 찾기, 피하기, 대피·신고 순서를 검사했다.
- 기존 교사용 연결 자료 25개 유형·장소 조합과 재시도·결과·공유 주소·영상 필터를 검사했다.

## 확인 한계

최종 브라우저 조작 도구와 Windows 점검 도구는 `failed to write kernel assets (os error 3)`로 초기화되지 않았다. 최종 브라우저 렌더링 전체 화면을 자동 캡처하지 못했으며 이전 화면을 최신 검증 결과로 재사용하지 않았다.

실제 전자칠판·태블릿의 터치, 음성 재생, 영상 공개 상태·자막·감각 자극과 학생별 이해·실제 안전 행동은 별도 확인 대상이다. 실제 시설의 피난계획·인솔자·필요한 지원이 우선이다. 자동 완주만으로 교육 내용의 충분함이나 안전 수행을 인증하지 않는다. 공개 서버 배포 검증은 포함하지 않는다.
