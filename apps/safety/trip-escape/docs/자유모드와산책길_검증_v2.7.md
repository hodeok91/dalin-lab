2026-11-15. 로컬 소스 기준. 기존 19개 스테이지·104문항·버스 이동 돌발 1문항의 구성은 유지한다. 로컬 저장·ZIP은 GitHub 업로드나 공개 배포를 뜻하지 않는다.

## 산책길 규칙

- 시작 전 노말·도전을 선택한다. 노말과 천천히 속도가 기본값이다. 모드는 플레이 도중 변경하지 않는다. 기록은 모드·속도로 구분한다.
- 두 모드 모두 벌·뱀·젖은 바닥을 점프로 무시할 수 없다. 각 구간의 안전 통로를 보장하고 연속 구간 사이 이동 시간도 확인한다. 전폭 벌떼·뱀·물·대왕 몬스터를 생성하지 않는다.
- 도전에서 빈 통로의 망토를 실제로 획득하면 세 구간 앞에 낮은 가지를 배치한다. 망토가 없으면 전폭 장애물은 없다. 가지가 가까워지면 점프 버튼이 활성화된다. 너무 이른 누르기는 망토를 소모하지 않는다. 망토 점프는 공상의 게임 장치이며 실제 동물·물가 대응을 대신하지 않는다.
- 물은 점프 대상에서 제외했다. 작은 돌·젖은 바닥·벌·뱀은 우회하고, 전폭 점프 구간은 낮은 가지 한 종류만 사용한다. 안전별은 빈 통로에만 놓인다.
- 맵은 9:16, 현재 구간과 다음 구간들을 미리 표시한다. 도로·바닥 장애물은 같은 카메라 이동량을 사용하고, 형아맨은 뒤를 보는 걷기 두 포즈로 움직인다. 키보드 방향키·화면 버튼을 누르고 있는 동안 연속 이동한다. 터치 취소·캡처 해제·포커스 이탈·팝업·탭 숨김에는 입력을 정리한다.

점프 동작에는 제공한 그림에서 글자·화살표·장식 구름을 제외한 투명 캐릭터를 사용한다. 판정은 제공한 다섯 이미지로 표시하며 중복 문구를 화면에 덧붙이지 않는다. 난이도 변경은 시작 전만 가능하다.

홈의 자유 모드는 스테이지 하나를 처음부터 다시 하거나 장소별 게임만 바로 시작한다. 미니게임 다시하기는 게임의 점수·진행·노래·시계를 초기화하고 선택한 난이도·모드·보조 설정을 유지한다. 찾기·비교 찾기·준비 카드·선 연결·새 장소 게임에도 같은 다시하기 진입을 제공한다. 원래 연결 수업의 찾기 완료 뒤 선택 문제로 가는 함수 누락도 복구했다.

## 실제 브라우저 증거

Edge headless의 실제 렌더링과 입력을 사용했다. 키보드 down/up, 마우스 down/up, Chromium의 native touchStart/touchEnd를 실행했다. 게임 상태를 주입해 완료시키지 않았다. 읽기 전용 DOM 값으로 위치·프레임·점수를 관찰했다.

- 1440×1080, 1024×768, 390×844에서 맵 가로/세로=0.5625를 확인했다. 키보드·화면 버튼·터치를 유지하면 이동하고 해제하면 정지했다. 가로 넘침과 JavaScript 오류는 없었다. 휴대폰에서 모드 선택·시작 버튼이 하단 지원 도구와 겹치던 부분을 발견해 수정했다.
- 실제 UI로 도전 시작→망토 획득→활성화된 점프 버튼→낮은 가지 통과를 진행했다. 통과 후 남은 기회는 3/3이었다. 자동 입력은 UI 방향키와 버튼만 사용했다.
- 실제 WAV를 재생해 점프 입력 후 새 캐릭터 그림과 이동을 확인했다. 네 난이도 선택과 다시하기 후 시작 대기 화면도 확인했다. 149.84초 전체 오디오 완료 증거는 v2.6 기록을 유지한다.
- 실행 JSON은 별도 캡처 폴더의 native-input-report.json, native-game-report.json이다. 화면은 합성 시안이 아닌 브라우저의 원본 캡처다.
