# 효과음·공원 생존 피하기 v2.5

2026-11-14

## 효과음

원본 index.html의 sfx와 BGM을 대조했다. 재구성 앱에는 리듬 박자음만 연결되어 있고 공통 효과음·배경음 연결이 누락되어 있었다. sound.js에 선택, 정답, 다시 시도, 단서 발견, 숨은 그림, 스테이지 입장·클리어, 돌발 알림을 연결했다. 기존 audio의 bus/rest/park/museum/room/escape MP3를 다시 포함한다.

학습지원에서 읽기 음성·게임 효과음·장소 배경음을 각각 조절한다. 처음 조작 후 오디오를 활성화한다. 배경음 볼륨은 0.12, 해설·대화·팝업 동안 0.025이며 리듬 게임과 다른 화면·숨겨진 탭에서는 멈춘다. 효과음은 짧은 sine/triangle 음을 사용하며 큰 부저나 경적을 반복하지 않는다. 재생 실패는 다음 미션 진행과 분리한다.

실제 Edge에서 Web Audio 노드의 발견음 시작, 음소거, 공원 MP3 200 응답 및 재생 완료 알림을 확인했다. 실제 사용 기기의 스피커 출력을 귀로 확인한 것은 아니다. 확인 화면은 별도 `미리보기/효과음_브라우저검사.png`이다.

## 공원 생존 피하기

공원 기본 이야기의 피하기 과제와 선생님 메뉴의 공원 피하기에 적용한다. 위험 그림이 위에서 내려오고 화면 왼쪽·오른쪽 버튼 또는 PC 방향키로 세 칸을 이동한다. 일정 횟수로 끝내지 않고 남은 기회 3번을 다 사용할 때까지 기록에 도전한다.

- 시간 1초마다 10점, 피한 그림 하나마다 50점. 이동 연타로는 점수를 얻지 않는다.
- 진행할수록 속도가 오르되 상한을 둔다. 천천히·보통 모드의 상위 기록은 구분한다.
- 충돌 시 한 번만 기회를 줄이고 잠깐 멈춘다. 한 장애물에 여러 번 차감하지 않는다.
- 일시정지·팝업·숨겨진 탭 동안 시간·점수·낙하 진행이 멈추며 복귀 후 이어진다.
- 종료 후 이번 점수·버틴 시간·피한 그림·최고·상위 5개를 확인하고 다시 도전하거나 다음 과제로 이동한다.
- 이름 없이 같은 기기에 기록을 보관한다. 게임 안의 기록 지우기는 다른 학습 설정을 삭제하지 않는다.
- 형아맨 원본 HA 복장과 기존 위험 그림을 사용한다. 실제 벌·뱀·물가에 접근하는 행동과 구분하는 안내를 표시한다.

## 검증

전체 자동 테스트 100개 통과. 기존 진행 경합·음성 실패·전체 장소와 재난 분기 완주를 포함한다. 새 검사에는 오디오 활성화·늦은 재개 후 음소거·배경음 중단, 피하기 150구간 생존·점수·충돌·속도·일시정지·재시도·기록 중복 방지, 9곳 32개 찾기 문장과 답 영역 중복 검사가 있다.

실제 Edge에서는 방향키 이동·일시정지 후 재개·3회 충돌 후 결과와 기록 저장을 확인했다. 1024×768 화면에서 점수판·게임·좌우 버튼을 함께 확인했다. 실기기 터치 감도와 학생 대상 사용성 검사는 별도이다.
