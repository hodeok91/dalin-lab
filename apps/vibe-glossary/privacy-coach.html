형아맨 바이브코딩 코치 (크롬·엣지 확장 프로그램) 개인정보처리방침

시행일: 2026년 11월 4일 · 만든 곳: 달인 연구소 (명현학교 특수교사 지호덕)

1. 무엇을 하는 프로그램인가요

교사 연수용 바이브코딩 학습 도우미예요. 구글 제미나이(gemini.google.com)와 구글 AI 스튜디오(aistudio.google.com) 화면 위에 설명 말풍선을 띄우고, 학습 퀘스트를 했는지 확인해요.

2. 확인하는 정보

  • 지금 열린 탭이 제미나이·AI 스튜디오인지 (주소)
  • Canvas 켜짐, [Preview]·[링크 복사] 버튼 누름 같은 화면 동작
  • 학습자가 보낸 프롬프트 글 — 퀘스트 채점(핵심 낱말 포함 여부)에만 사용

3. 저장과 전송

  • 모든 정보는 사용자의 브라우저 안(chrome.storage)에만 저장돼요. 프롬프트 글은 브라우저를 닫으면 지워지는 임시 저장소(session)에만 잠시 남아요.
  • 개발자 서버를 포함해 어떤 외부로도 전송하지 않아요.
  • 깬 퀘스트 기록은 달인 연구소 웹 교실(hodeok91.github.io/dalin-lab)에서 내 진행 상황을 보여 주는 데만 쓰여요. 이것도 같은 브라우저 안에서만 오가요.

4. 읽지 않는 것

구글 계정·비밀번호, 대화 기록 전체, 첨부 파일, 다른 사이트의 내용은 읽지 않아요. 두 사이트 밖에서는 동작하지 않아요.

5. 지우는 방법

코치 창 아래의 [기록 지우기]를 누르거나 확장 프로그램을 삭제하면 모든 기록이 지워져요.
