제미나이 캔버스나 구글 AI 스튜디오, 클로드로 만든 웹앱은 대부분 **HTML 파일 하나**예요. 이 파일을 달인 연구소 저장소에 넣으면 `내주소/apps/앱이름/`으로 바로 열려요.

## 1. HTML 파일 받기

- **제미나이 캔버스**: 캔버스 오른쪽 위 *공유/내보내기* → 코드 복사 → 메모장에 붙여 넣고 `index.html`로 저장
- **AI 스튜디오(Build)**: *Download* 로 받은 zip을 풀기. 빌드가 필요한 프로젝트라면 `npm run build` 뒤 `dist` 폴더 안 파일을 씁니다.
- **클로드·코덱스로 만든 것**: 결과 폴더 그대로

## 2. 저장소에 올리기

1. GitHub 저장소 → `apps` 폴더 → **Add file → Upload files**
2. 파일 이름 앞에 폴더를 붙여서 올려요. 예: `my-quiz/index.html`
3. **Commit changes**

1~2분 뒤 `https://내주소/apps/my-quiz/` 로 열립니다.

## 3. 홈페이지 목록에 보이게 하기

`data/apps.json` 에 한 덩어리를 추가해요.

```json
{ "id": "my-quiz", "name": "우리반 퀴즈", "icon": "❓", "category": "게임",
  "type": "웹앱", "status": "live", "desc": "한 줄 설명",
  "url": "apps/my-quiz/", "tags": ["퀴즈"], "added": "2026-11-04" }
```

저장하면 앱 목록, 검색, 인기 순위에 자동으로 들어가요.

## 주의할 점

- 앱 안에 **API 키**(제미나이 키 등)를 그대로 넣으면 누구나 볼 수 있어요. 키가 필요한 앱은 따로 상의해 주세요.
- 학생 개인정보를 저장하는 앱은 올리기 전에 한 번 더 점검해요.
